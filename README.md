# TMARS Crypto Library

A library for TMARS memecoin with support for TON and Solana blockchains and a bridge using Wormhole.

## GitHub Copilot - GPT-5 Codex Preview

This repository is configured to use GitHub Copilot with GPT-5 Codex preview enabled.

### Features Enabled

- **GPT-5 Model**: Latest AI model for code completion and suggestions
- **Codex Preview**: Advanced code generation capabilities
- **Chat Assistance**: AI-powered chat for code explanations and refactoring
- **Inline Suggestions**: Real-time code completion as you type

### Configuration Files

The following files configure GitHub Copilot for this repository:

- `.github/copilot-instructions.md` - Instructions and context for Copilot
- `.github/copilot.json` - Copilot model configuration
- `.vscode/settings.json` - VS Code Copilot settings

### How to Use

1. Install GitHub Copilot extension in VS Code
2. Make sure you have an active GitHub Copilot subscription
3. Open this repository in VS Code
4. The GPT-5 Codex preview model will be automatically activated

### Development

```bash
# Install dependencies
npm install

# Build the project
npm run build

# Start the application
npm start
```
